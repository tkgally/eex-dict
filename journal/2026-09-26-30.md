# 2026-09-26 (thirtieth run): the seventeenth lint pass

## What this run did

This was the eleventh cycle of this session, and a **lint** run. A lint run adds no new words. It checks the whole dictionary for problems that build up over time and re-measures how often each reviewer model is right. The mode selector (`tools/next_mode.py`, which picks each run's kind of work) forces a lint pass after five runs without one. The closure run before it merged as pull request #98. Lint makes no paid calls, so this run cost nothing.

## The mechanical checks

- **Size caps and links.** Every file is within its word cap, and every relative link resolves.
- **Defining vocabulary.** The definitions checker went through all 647 entries. None uses a word outside the defining vocabulary without an entry for it. (The defining vocabulary is the list of about 2,400 basic words that definitions are written in.)
- **Old claim files.** Four were deleted. A claim file reserves words for one run, and these four named only words that now have finished entries.

## Back-links

The cross-reference tool adds a back-link when one entry names another as a synonym, an opposite, or a word to compare, but the other entry does not point back. This time it added eight, all to words written in the last few cycles. Each was checked by hand, because the tool sometimes chooses the wrong sense of the target entry.

Six were right:

- *climb* and *drop* sit beside the "increase" sense of *rise*
- *fix* (a date) beside the "plan" sense of *arrange*
- *order* beside the "put in order" sense of *arrange*
- *realize* (a dream) beside *achieve*
- *take* (the bus) beside the passenger sense of *ride*

Two were on the wrong sense and were moved:

- *jump*, in the sense *prices jumped*, had landed on the "go up" sense of *rise* (smoke rising). It now sits on the "increase" sense.
- *drive* had landed on the passenger sense of *ride*. It now sits on the first sense, "control a bike or a horse". That is where the contrast with *drive* matters, and where the entry's learner error (*I ride my car to work*) points.

A second run of the tool added nothing, which confirms the moved links stay where they are.

## Reviewer precision

Precision is the share of a reviewer's issues that led to a fix. The routine switches off a kind of issue for a reviewer when its precision falls under 30 percent over twenty or more decisions. No kind of issue crossed the line.

The closest remains reviewer-a's pronunciation objections, at 32 percent over 111 decisions. It raised none that were rejected in the last five runs. Reviewer-b's formatting objections are at 51 percent and still falling. Most of the rejected ones repeat the same objection: that a translator's note should not begin with the headword in quotation marks. That habit is settled house practice. The details are in `wiki/notes/reviewer-precision.md`.
