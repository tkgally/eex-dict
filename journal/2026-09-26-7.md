# 2026-09-26 (seventh run): ten new verbs, *invest* to *kiss*

## What this run did

This was a **build** run: it wrote new dictionary entries. The scheduler (`next_mode.py`, the script that picks each run's kind of work) chose it because building was the kind of work most overdue. Before starting, the run checked for unfinished work left by earlier runs. There was no open pull request (a proposed change waiting to be merged). One old working branch, `claude/relaxed-bell-ngyr08`, was still on GitHub, but all of its work was already in the main copy. The run's tools cannot delete branches, so it added one line asking the owner to prune it to `reviews/needs_curator.txt`, the list of things only the owner can do.

The run drafted ten common verbs from band 1, the most basic band of the word list: **invest, invite, involve, join, judge, jump, keep, kick, kill, kiss**. Each entry has senses (separate meanings) with definitions, grammar, examples, and collocations (words that often go together), plus notes on common learner mistakes and on traps for translators. *Keep* is the largest, with eleven senses and two phrases; *kiss* has one sense.

## Checks and reviews

Every entry went through the full pipeline, the fixed series of checks each new entry must pass:

- **Format and inflections.** All ten entries passed the format check. The inflection tool generated every verb form; only *keep* (*kept*) needed the table of irregular forms.
- **Pronunciation.** A panel of models checked the American and British transcriptions and compared them with the open CMU pronouncing dictionary. All twenty were verified, with no disagreements.
- **Reviewers.** Two reviewer models from other companies read every field. One reply for *join* could not be read and was re-run. The two raised 52 issues in all, 30 of them marked blocking (must be settled before the entry is published). The run decided each one and recorded it in the decision log: 38 fixes accepted, 14 rejected.

**What the reviewers got right.** The most useful finding came up five times: a definition was narrower than the examples under it. For example, *keep* sense 8 said "stop someone from doing something", but one of its examples was *a fence keeps the dogs out of the garden*. It now reads "stop someone or something from doing something or from going somewhere". The same problem was fixed in *keep*'s "records" sense, which had to cover *keep score*; in *join*'s senses for being with people (to cover *join the line*) and for roads meeting; and in *involve*'s third sense. Several absolute claims were softened because they were not strictly true. **Invest on** is used in finance, **join with someone** is correct English, and *involve* can occasionally be used in the continuous form. The *join with* learner error was removed completely. The informal *kill* sense (*Mom will kill me*) now makes it clear that the subject is the angry person.

**What was rejected, and why.** Reviewer-b again objected to the quoted headword at the start of adaptation notes on seven entries. The project decided earlier that this is allowed, so those objections were rejected. Two requests for a pattern showing a verb with no object were rejected because the project's closed list of grammar patterns has no such value; the transitivity field already shows that use. One reviewer-a claim that an adaptation note on *keep* named a particular language was rejected: the note names none.

## Cross-references

When a new entry lists an existing entry as a synonym or an opposite, a tool adds a matching link back. It added four links this time. Two were on the wrong sense and were moved by hand. *Kill*'s "end something" sense had been linked to *destroy*'s "kill an animal" sense; it now links to "ruin". *Jump* (rise suddenly) had been set as the opposite of *fall* in its "drop down" sense; it now goes with "go lower". Words the new entries refer to that have no entry yet, such as *leap*, *murder*, *prevent* and *keep up*, were added to the queue of words to write (24 new rows).
