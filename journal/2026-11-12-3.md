**A tool fix.** One tooling problem had been recorded six times since September, so this cycle fixed it. The tool that writes each noun's plural form (`tools/inflect.py`) always wrote "no plural" for a noun whose senses are all uncountable. It did this even where English has a real plural in some uses: *monies* or *moneys* in legal writing, *the rains*, *the makings of*, *finances*, *energies*. Each time, the reviewers objected, and each time the objection had to be rejected as a tool limitation. Now a line in the project's own table of irregular forms can give such a noun its plural. The tool's default stays "no plural" for every other uncountable noun, and for longer phrases ending in these words (*pocket money* still has no plural). I added table lines for *money*, *energy*, *finance*, *rain* and *making*, each marked "usually no plural". The five entries' inflections were regenerated, and a unit test covers the new behaviour. A future case needs only one table line.
