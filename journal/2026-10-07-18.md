# 2026-10-07 (18): originality — the twenty-third check, two definitions rewritten

*Cycle 2 of the 16:43 UTC run. Run id `20261007T170423Z-2e317i`.*

## What this cycle did

The scheduler (`tools/next_mode.py`, the script that picks each cycle's job) is set to run an **originality check** every tenth run, and this was run 300. An originality check makes sure the dictionary's wording is our own and not copied from a published dictionary. The tool picks ten fields at random from the dictionary's entries, mostly definitions. I then searched the web for the exact wording of each and asked one of the outside reviewer models whether each reads as copied. Search results decide the verdict; the model's opinion is only a second signal, because past checks showed it is unreliable in both directions.

The ten fields came from *way* (the idiom *one way or another*), *come*, *border*, *see* (*we'll see*), *package*, *order* (*out of order*), *bridge* (*burn your bridges*), *bag*, *cheese* (its usage note on countable and uncountable uses), and *job* (*just the job*).

## What the search found and what I decided

Six fields had no match anywhere: original. Two were short, plain definitions that any dictionary would write in much the same way (*come*: move toward the person speaking; *just the job*: *exactly what is needed*). These are classed as "generic overlap", which is not copying.

Two were close enough to a well-known learner's dictionary to rewrite:

- **bag**, first sense. Ours read *a container made of cloth, paper, plastic, or leather, used for carrying things*. The published entry lists the same four materials and the same *used to carry things* ending. It now reads: *a container with an opening at the top, usually soft, that you carry or keep things in*.
- **package**, first sense. Ours read *something wrapped in paper or packed in a box, especially so that it can be sent to someone*; the same dictionary's entry for *parcel* has the frame *something that is wrapped in paper ... so that it can be sent*. It now reads: *a box or a wrapped object that is sent by mail or delivered to someone*.

Neither match was word for word, but both followed the published structure closely, and the house rule is to rewrite when in doubt. The reviewer model (reviewer-a, the OpenAI model, asked without its hidden reasoning step) called all ten "original", including these two. That is a useful reminder that its answers are not evidence either way: in earlier checks it called everything "copied".

A rewritten definition counts as a change to the entry, so both entries went back through the review panel. Reviewer-a raised 6 issues, all on parts of the entries this check had not touched; reviewer-b raised none. I agreed with 4. *Package* in the sense of a container of goods for sale (*a package of cookies*) was labelled American, but the entry's own note says British English uses it too, so the label went, and the definition now says it includes the contents. *Sold together as one* became *sold together for one price*. I rejected two: the reviewer said *suitcase* is not a synonym of *bags* in the travel sense, but in *pack your bags* the two are used interchangeably; and it said British English does not mostly use *parcel* for something sent by mail, which it does.
