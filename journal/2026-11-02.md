# Run report, 2 November 2026

## Cycle 1: originality

**What this cycle was.** Every twentieth scheduled run is an *originality check*: a spot test that the dictionary's wording is its own and not copied, even unconsciously, from a published dictionary. The selector (`tools/next_mode.py`, the script that picks each cycle's job) forced it this time because this was run 640. Before starting, the usual pre-flight checks found nothing waiting: no unmerged pull requests from earlier runs, no leftover branches, nothing in the owner's inbox, and no public "entry report" issues.

**How the check works.** A script picks ten fields at random from the 3,533 reviewed entries, mostly definitions. For each one I ran a web search for the exact wording in quotation marks, looking only for whether a published dictionary uses the same words. Then I put the ten to one of the two AI reviewers with a fixed question: does this read as copied, and if so, quote the source. Each field then gets one of three verdicts: *original*; *generic overlap* (a short, plain definition that any dictionary would write in much the same way, which is not copying); or *rewrite* (it matches a published dictionary's distinctive wording, so it must be reworded).

**What was found.** No exact-phrase search found a match. The reviewer, reviewer B this time (the previous checks asked reviewer A, and the last handover note asked for B), called nine fields original and one "cannot tell". But one of its reasons mattered more than its verdict. For `character-n` sense 1, our definition was *all the qualities that make one person different from other people*. The reviewer called it original but said it was "a slight rewording" of the Oxford learner's dictionary, and quoted that dictionary's wording. A second search confirmed it: Oxford defines the sense as *all the qualities and features that make a person ... different from others*. Ours followed the same frame, with only two words changed, so I judged it a rewrite. Sense 2, *the particular qualities that make a place or thing different from others*, was built on the same frame, so I rewrote it too.

Final tally: 6 original, 3 generic overlap (`one-another-pron`, `work-out-phrv`, `floor-n`), 1 rewrite (`character-n`). The three overlaps share short ordinary phrases with learner's dictionaries (*the surface that you walk on* for *floor*, *each … the other or others* for *one another*) in differently built sentences. A reciprocal pronoun or a floor can hardly be defined any other way.

**The rewrite.** Sense 1 now reads *the whole set of a person's qualities, good and bad, that makes them the kind of person they are*; sense 2 reads *the general nature of a place or thing, made up of the features that people notice most about it*. My first try at sense 1 (*the kind of person someone is, shown in the way they usually think, feel, and behave*) was dropped on rereading. It collided with the entry's own note telling *character* apart from *personality*, which describes personality as "a person's usual way of feeling and behaving". The final wording keeps the distinction the note draws: character is the whole set of qualities, including moral ones.

The rewritten entry went through the full pipeline: format and schema checks, the inflection and pronunciation checks (both verified), and both reviewers reading every field. They raised 9 issues, none blocking. I applied 3: sense 4, the character in a story, now mentions television shows, as its examples already did; the phrase *out of character* lost an explanation that only pointed to *in character*; and a sentence in the synonym note with two colons was smoothed. I rejected 6, each with a logged reason. Among them: a request to drop the false-friend note because the learner-error note "says the same thing" (the two are different traps, one about translation and one about usage); a request to mark *bad temper* with single asterisks (the style guide says a phrase named as a word takes the double mark); and a proposal to reorder senses that earlier reviews had already settled.

**Spend.** US$0.06 (the reviewer question and the panel), out of a US$15 daily budget.

**What did not work.** Nothing broke. One lesson is recorded in `NEXT.md`: reviewer B's verdict alone would have missed the one real problem. Its quoted comparison caught it, so later checks should search any quotation the reviewer gives, whatever its verdict.

**What is next.** The selector picks the next cycle's job. The standing queue still leads with the cross-reference audit, closure building (adding words the dictionary's own definitions use), and the coverage reading of band-1 entries.

**For the owner.** Nothing new. The standing items in `NEXT.md` remain: the curator line on names after titles, the charter's "two non-Anthropic reviewers" sentence, and the open pronunciation disputes.
