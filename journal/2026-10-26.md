# Run report, 2026-10-26

## Cycle 1: site

**What this cycle did.** The scheduler (`tools/next_mode.py`, the script that picks each cycle's kind of work) chose a site check. A site check rebuilds the public website from the dictionary's entry files and then opens the pages in a real browser, at a phone width and a desktop width, to make sure nothing is broken. The scheduler gave this reason: of all the kinds of work that were allowed today, the site check had gone longest without being done. Writing new entries from the words the dictionary already uses ("closure") is still blocked, because your ruling of 2026-10-24 says milestone 1, the list of about 2,400 basic defining words, must be finished first; 120 of those words are still unwritten.

Before the site check, the cycle did its usual safety checks. There were no open pull requests left behind by an earlier run, and no "Entry report" issues from readers on GitHub. One leftover branch, `claude/gallant-carson-ax7wls`, belongs to yesterday's run; its work is all on `main` already, so nothing was lost. This run's tools cannot delete branches, so I added a line to `reviews/needs_curator.txt` asking for it to be pruned.

**The result.** The build tool (`tools/build_site.py`) turned 2,924 entries into 2,538 headword pages. A headword page can hold more than one entry, for example a noun and a verb with the same spelling, which is why there are fewer pages than entries. No entries were held back as unfinished drafts, and there were no renamed entries needing redirect pages.

The browser check (`tools/site_check.py`) ran 79 tests, and all 79 passed. Among other things, it confirmed that:

- no page scrolls sideways on a 360-pixel phone screen, across all 2,544 pages;
- searching for an inflected form such as *ran* finds **run** first, and pressing Enter opens it;
- a phrase can be found by its words (*a cut above* finds *a cut above someone or something*), and a misspelling such as *abiilty* offers "Did you mean **ability**";
- hovering on a linked word shows a short preview of its entry;
- the translator's view can be turned on and off, and the setting survives a reload;
- dark mode works, the menu behaves at both widths, and the sense menu on long entries such as **act** jumps to the right sense;
- a cross-reference to a word with no entry yet is shown in plain grey, as your ruling C2 asks;
- an address for a page that does not exist gives a "not found" page that searches for the word.

The twelve adjectives written in yesterday's last cycle (**bent** to **lucky**) appear and render normally.

**What changed.** Nothing in the build tool or its page templates needed fixing, so no code changed. The website files themselves are never stored in the repository; GitHub builds and publishes them after each merge.

**Spend.** Nothing. A site check uses no paid model calls.
