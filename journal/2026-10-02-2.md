# 2026-10-02 (2) — Thirteenth originality check: no rewrites needed

*Second cycle of the run that began at 00:43 UTC. A "cycle" is one unit of work with its own pull request; a run does up to four.*

## What this cycle did

The mode selector (the script that picks each cycle's job) forces an **originality check** every tenth run, and this was run 170. An originality check makes sure the dictionary's wording is its own and has not been copied, even by accident, from a published dictionary.

The check works like this:

1. The tool `tools/originality_check.py` picks ten fields at random from the whole dictionary. This time all ten were definitions.
2. For each one, I ran a web search for the exact wording in quotation marks and looked only at whether a published dictionary shows the same words.
3. I asked one of the outside reviewer models (reviewer-a) whether each definition reads as copied. It may answer "copied" only if it can quote the published wording.

Each field then gets one of three verdicts:

- **original**: no match.
- **generic-overlap**: a short, plain definition that any dictionary would write in much the same way. This is not copying.
- **rewrite**: a match with a published dictionary's distinctive wording. The field is then rewritten and reviewed again.

The ten definitions sampled were:

- *represent*, sense 4: "show or describe someone or something in a particular way, in a picture, a story, or a film"
- *quit*, sense 3: "close a computer program"
- *cure*, sense 2: "end a problem or a bad situation"
- *all* (pronoun), sense 2: "every person or thing in a group being talked about"
- *family*, sense 2: "all the people who are related to you, including grandparents, aunts, uncles, and cousins"
- *either* (pronoun), sense 1: "one or the other of two people or things, when it does not matter which"
- *aircraft*: "a vehicle that can fly, such as a plane"
- *upon*, sense 4: "used between two words that are the same to show a great number of things, one after another" (as in *mile upon mile*)
- *without*, sense 2: "not doing a particular thing"
- *clean*, sense 1: "remove dirt, dust, or marks from something"

## What the search found

None of the ten wordings turned up in a published dictionary.

- **Seven are original.** The searches brought back unrelated pages: genealogy guides for *family*, cleaning and photo-editing guides for *clean*, pages about word repetition for *upon*.
- **Three are generic overlap.**
  - *quit*: "close a computer program" is three plain words that any definer would use.
  - *either*: one search summary gave a learner dictionary's wording, which uses the same key idea, "when it does not matter which". That idea is the rule itself, and the rest of our definition is worded differently.
  - *aircraft*: a summary showed another dictionary starting "a vehicle which can fly, for example". "A vehicle that can fly" is the obvious short way to define the word, so this is the kind of overlap the style guide says is not copying. It sits close to the line, so I note it here in case the owner disagrees.

No rewrites were needed.

## What the reviewer model did

reviewer-a answered "copied" for all ten, every time naming the same well-known learner dictionary. Each time, the "quotation" it gave was simply our own definition, word for word. Web search found none of them. Asking for a quote was meant to stop unsupported "copied" answers, and for several checks it seemed to work. This time it did not: a quote that is just our text repeated back proves nothing. As in the last five checks, the verdicts come from search evidence alone. I added a short entry about this to the reviewer-noise note (`wiki/notes/reviewer-noise.md`), where earlier patterns are recorded. The full record is `reviews/originality/2026-10-02.md`.
