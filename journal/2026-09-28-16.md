## What it found and fixed

**Cross-references.** A cross-reference is a link from a sense of one entry to a related entry: a synonym, an antonym, or a word to compare. The cross-reference tool makes these links two-way. When entry A points to entry B, it adds the matching link in B (a "back-link"). This pass added three back-links:

- *destroy* in its sense "defeat completely" lists *beat* as a synonym. The back-link landed on *beat* meaning "hit repeatedly", which is wrong. I moved it to *beat* meaning "defeat" and added a note (*they destroyed us* is an informal way to say you lost badly).
- *believe* now points to *feel* (have an opinion), which is right.
- *arrive* now has *go* (leave) as its opposite, which is right.

The tool also reported two "type mismatches", where each side of a pair called the other something different:

- *but* and *yet*
- *if* and *whether*

In both, the target entry listed the other word twice: once as a synonym and once, with no note, under "compare". I removed the stale "compare" link.

Earlier cycles of this same run met the same problem twice (*break* under *beat*, and *axe* under *cut*). About one back-link in three still lands on the wrong sense when the two entries share few words. The note on this tool problem is updated; the fix is still owed.

**Vocabulary.** The defining-vocabulary check found no violations across all 669 entries. It queued one new word, *bubbles* (noun), from the definition of *boil*. That row was wrong: *bubbles* is a plural. I marked it a duplicate and queued *bubble* instead. (The closure queue's guesses about base forms and parts of speech have gone wrong before; the note on that is already open.)

**Claims.** The claim tool removed one old claim file, from this run's third cycle, whose words now all have entries. (A claim file reserves words so that two runs never draft the same one.)

**Reviewer precision.** I measured how often each reviewer's objections turn out to be right, by kind of issue. A kind of issue that is right less than 30 percent of the time, over twenty or more decisions, is switched off for that reviewer. None crossed the line this time. The first reviewer's pronunciation objections, right 32 percent of the time over 122 decisions, are still the nearest. All three of its recent pronunciation rejections were the same settled point: American transcriptions drop the length mark.

**The wiki.** Every page is listed in the index, and no link is dead. The list of questions for the owner has no stale items, and the curator list (items waiting for a person) has no duplicates. One small count in NEXT.md disagreed with itself. It gave 39 and 38 for the number of one-sense entries that still carry a signpost; the true number is 38.
