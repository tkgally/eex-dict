# Run report, 2026-09-25 (sixth run of the day): a second reading of twenty pronouns

## What this run did

This was a scheduled, unattended run of the dictionary project. The scheduler (the script `tools/next_mode.py`, which picks each run's kind of work by how long each kind has waited) chose **review**: a second reading of entries that have been checked only once. No entries were waiting in `draft` status (drafted but not yet checked), so the run took the twenty oldest entries that had been through only one round of the review panel. The panel is two language models from other companies, called reviewer-a and reviewer-b, that read every field of an entry and report problems with a fixed set of verdicts. All twenty were personal pronouns and similar words written on 2026-09-19: *everybody, everyone, everything, few, he, her, hers, herself, him, himself, his, I, itself, me, mine, myself, ours, ourselves, she, somebody*.

Before starting, the run checked for unfinished work from earlier runs: there was no open pull request and no leftover branch, and the inbox for the owner's instructions was empty.

## What the reviewers found and what I decided

Reviewer-b's reply for three entries (*everybody, everything, him*) came back cut off and could not be read, so I sent those three to reviewer-b again; the second replies were complete.

In all, the reviewers raised 22 issues, 15 of them marked blocking (meaning the entry should not stand without a decision). I read each against the entry and decided: 14 applied, 8 rejected, none sent to the owner.

The real problems:

- ***itself***: the emphatic sense (*the house itself is small*) was defined only as "the thing apart from anything connected with it"; it also just gives weight to a noun (*the idea itself is not new*), so the definition and explanation now cover both. The phrase *by itself* had a vague third meaning, "without anything else happening"; it now reads "without any person making it happen". The usage note offered *the door opened itself* as a less common form; it is not normal English, so the note now says English uses *by itself* here.
- ***ourselves***: the definition said the action affects the speaker and others "together", which is too narrow (*we introduced ourselves* can mean one by one), and the emphatic sense said it can follow any noun, when in practice it follows *we* or ends the clause. Both fixed.
- ***ours***: a translator's note claimed the two-syllable pronunciation is more common when the word is stressed. That is not well supported; the note now just says both one- and two-syllable forms are correct.
- ***himself*, *myself***: the learner-error notes said the word is used "only when the subject and object are the same person", which contradicts the emphatic sense (*he built it himself*). They now say this is true of the word used as an object.
- ***his***: the note calling it "the only" independent possessive (a possessive standing alone, as in *it's his*) with the same spelling as the form before a noun now says "the only common" one, since *its* can technically do the same.
- ***everything***: an entry with only one sense should have no signpost (the short label that helps a reader pick among senses); this one had "every thing". Cleared, and the same on *everybody* and *everyone*.

Rejected: flags about pronunciation conventions the project has already settled (secondary stress on *-one* in *everyone*, a stress mark placed after a syllable break, and a claim that American *fju* lacks a vowel it plainly has), one flag against the phrase "and so on", and two flags that the reflexive rule was stated too absolutely, when the notes were already limited to the reflexive use.

While these entries were open I also fixed something the reviewers did not flag: four reflexive entries showed wrong forms such as *come with himself* in italics inside notes, which the house style forbids (wrong forms belong only in the learner-error box). I reworded them.

## Something found for later

A scan showed 45 one-sense entries carrying a signpost, against the style guide. The validator does not check this. Because a signpost is written content, no script may clear it; the remaining 42 will be fixed by hand when a review opens them. I wrote this up in `wiki/notes/one-sense-signposts.md`; a validator warning could be added in a later run.
