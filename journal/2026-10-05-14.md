## What this cycle did

The selector (`tools/next_mode.py`, the script that picks each cycle's job) chose **originality**. It forces this check every tenth run. The check asks whether any of our wording matches a published dictionary. Every entry must be written from the drafter's own knowledge, never copied, and this check is how we catch a slip.

A script picked ten fields at random from the whole dictionary. Most were definitions of senses and phrases; one was a usage note. For each, I ran an exact-phrase web search and looked at whether a published dictionary shows the same wording. I also asked one outside reviewer model (reviewer-a) whether each "reads as copied". It may answer "copied" only if it can quote the published wording. Each field then gets one of three verdicts:

- **original**: no match;
- **generic-overlap**: a short, plain definition that any dictionary would write the same way, which is not copying;
- **rewrite**: a match with a dictionary's distinctive wording, which must then be rewritten.

## What was found

- **Eight original.** No match for *child* ("a person or thing whose character has been strongly shaped by a particular time, place, or influence") or *setting* (the metal part of a ring that holds the stone). There was also no match for *set* ("decide on a time, a price, a rule, a goal, or a limit"), *any old* under *old*, *open to discussion* under *discussion*, *throughout*, or *hang*, or for the usage note on *passed* and *past* in *pass*.
- **Two generic overlaps.**
  - *the other day* (under *day*) is defined as "a few days ago". Collins explains the phrase with the same three words, and no plainer way to say it exists.
  - *drive*, sense 2, is "travel somewhere in a car". Cambridge's definition opens with the same five words and then goes on. Short, plain glosses like this resemble every dictionary by necessity. Earlier checks treated *girl*, "a female child", the same way.
- **No rewrites.** No entry was changed.
