## What this cycle did

This cycle was a **lint pass**: a scheduled check of the dictionary and its knowledge base for problems a single entry's review cannot see. The scheduler forces one after five runs without one. It costs nothing, because it makes no calls to paid models.

The pass has a mechanical half (scripts that check every file) and a judgmental half (reading pages against each other). Nothing serious turned up. The changes were small: four cross-references added by a script, two catalog lines updated, and one stale line corrected in the baton file (`NEXT.md`, the note each cycle leaves for the next).

## The mechanical checks

- **Caps** (`tools/check_caps.py`): every size limit on the rule files, the style guide, and the wiki is respected.
- **Links** (`tools/check_links.py`): all relative links in the 507 knowledge-base pages resolve.
- **Back-links** (`tools/crossref.py --all --apply`): when entry A names entry B as a synonym, B should name A too. The script adds the missing mirror, but it always attaches it to B's first sense, which is sometimes the wrong sense, so every one is checked by hand. This time it added four, all pointing at adjectives built in this run's first cycle:
  - `major-adj` sense 1 now lists *big* and *important* as synonyms. Right: both senses mean important.
  - `mean-adj` now lists *cheap* as a synonym. The script put it on sense 2, the not-generous sense, which matches `cheap-adj` sense 4 (*not willing to spend money*). Right.
  - `loose-adj` now lists *free*. The script put it on sense 3 (*free to move around*), matching `free-adj` sense 7 (*not tied or held in position*). Right.
  None needed moving. The script also reported one known type mismatch: `lonely-adj` names *alone* as a word to compare, while `alone-adj` names *lonely* as a synonym. An earlier pass decided this is correct (the two entries see each other differently), and it stays.
- **Vocabulary** (`tools/lint_vocab.py --all --queue`): no definition anywhere uses a word that is outside the defining vocabulary and has no entry, so nothing was queued.
- **Claims**: three old claim files (records of which words a cycle took from the queue) were pruned.
