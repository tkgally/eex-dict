# 2026-09-26 (thirty-fourth run): the third originality check of the day

## What this run did

This was the fifteenth and last cycle of this session, and an **originality** run. An originality run takes a random sample of ten definitions and checks that none of them copies a published dictionary. The mode selector (`tools/next_mode.py`, which picks each run's kind of work) forces one every tenth run, and this was the hundredth. The run clock (the script that decides whether a new cycle may start) allowed this cycle to start one minute before its limit, after the review cycle merged as pull request #102.

For each definition, the run did three things:

- an exact-phrase web search, to see whether a dictionary site shows the same wording
- one question to a reviewer model: does this read as copied?
- a verdict, recorded in `reviews/originality/2026-09-26-3.md`

## What the searches found

None of the ten definitions appeared word for word on any dictionary page. Two came close enough in shape to be rewritten as a precaution, which is what earlier checks have done in the same situation:

- **inside** (preposition), sense 1, read "in or into the inner part of something". The search summary for another dictionary's *within* reads "in or into the interior or inner part; inside", which opens the same way. It now reads "within the walls, sides, or edges of something, or moving to a place within them".
- **old**, sense 4 (*my old teacher*, *our old house*), read "from an earlier time in your life; former". A learner's dictionary has "from a previous time or a period in the past; former", with the same shape and the same last word. It now reads "that you had, knew, or did before, but not any longer".

The other eight got these verdicts:

- **Original:** *for nothing*, *the thing* ("exactly what is needed"), *such as* used alone, and *quickly* ("for a moment").
- **Generic overlap:** *drop*, *act* (of a play), *open* (a meeting), and *don't mention it*. Each is a short, plain wording that any dictionary would be likely to write.

## What the reviewer said

The reviewer model, reviewer-a, called six of the ten "copied". Each time it named a well-known learner's dictionary and gave a quote, which is what the question asks for. But the quotes did not hold up:

- Three of them were simply our own wording, repeated back.
- Exact-phrase searches for all six found none of them on any page.

Earlier checks added the rule "quote the source, or do not say copied" because this reviewer used to call everything copied. For a while that stopped the false calls. This time it did not: the reviewer supplied plausible quotes that search cannot confirm. The verdicts therefore rest on the searches. The finding is written up in `wiki/notes/reviewer-noise.md` for a later run to act on. One option is to ask for a quote that differs from the text shown. Another is to drop the reviewer question.

## Reviewing the two rewrites

Both rewritten entries went back to the two reviewer models, which read the whole entry, not just the new definition. They raised 17 issues. Each has a logged decision: 6 applied and 5 rejected. Reviewer-b's first reply on *old* could not be read by the tool, so that role was run again, and its repeated issues account for the rest. The fixes were all in *old*:

- sense 3 (*The building is a hundred years old*) said "having lived", which does not fit a building; it now says "having existed"
- sense 6 (*good old Sam*) reads "known well and liked"
- *elderly* moved from the word family, which is for related forms of the same word, to "see also"
- the British *come round* became *come over*

The five rejections were reviewer-a's claims that *inside the house* and *inside the car* are adverbs. They have a noun phrase after *inside*, so they are prepositions, as the house rule says.
